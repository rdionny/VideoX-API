  1. Confira se a API está viva: abra /info no navegador. Deve aparecer um JSON com o mapa dos endpoints.
  2. Pegue uma lista de vídeos (troque o termo pela sua busca): 
    curl "BASE/videos?source=search&q=maga&count=5"
  3. Pegue os detalhes de um vídeo usando o slug que veio na lista: 
    curl "BASE/video/olimpkf8bba"
    A resposta inclui visualizações, capa grande e o MP4 pronto para tocar no player.

⚡ 5 fontes de dados

Uma única rota para home, busca, categoria, tag e canal — só muda o parâmetro source.

🖼 Capas prontas

Imagem grande para a tela de detalhes e thumbnail pequena para as grades, poupando dados do celular.

▶️ HLS adaptativo + MP4

O campo hls traz o M3U8 com todas as qualidades — o player troca de 240p a 1080p sozinho conforme a internet. MP4 direto segue disponível como fallback no ExoPlayer/Media3.

🛡 Tolerante a falhas

Cache de 60 s e nova tentativa automática quando o site responde uma página leve/anti-spam.

Atenção: os links de reprodução (MP4 e o M3U8) carregam um código de segurança com validade de ~1 dia. O jeito certo de usar é pedir os detalhes do vídeo neste momento e tocar em seguida — não guarde o link por dias. O conteúdo do site é para maiores de 18 anos.
